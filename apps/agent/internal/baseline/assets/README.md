Файлы, которые агент кладёт на сервер по эталону ("Исправить проблемы" в
"Обзоре" сервера). В бинарник попадают по явному списку `//go:embed` в
baseline.go: новый файл - добавить туда. Этот README в бинарник не попадает и
версию агента не меняет (Makefile не берёт *.md в хеш).
vps-portsync.py и юниты portsync* правятся только здесь. Какие порты открыть, считает агент
(internal/portsync, `vps-agent -portsync-state`), скрипт только применяет. Установленные
скрипт и юниты агент при запуске обновляет до встроенных, ставит недостающую службу
vps-portsync-xui.service и поднимает выключенный или изменённый path-юнит (RefreshPortsync).
