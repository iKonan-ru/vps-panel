# Изменения

Версии - [semver](https://semver.org/lang/ru/): X.Y.Z - стабильный релиз, X.Y.Z-beta.N -
пре-релиз (канал "бета"). Текст раздела версии становится описанием релиза на GitHub.

## 1.0.0-beta.8 - не выпущена

- Администратор создаётся при установке: логин спрашивается (Enter - случайный), пароль
  всегда случайный; в конце установки - сводка для входа (адрес, логин, пароль), как у других
  панелей. Мастера в браузере больше нет - до установки администратора панель никого не
  пускает.
- 2FA по-прежнему обязательна и настраивается при первом входе (QR и резервные коды).
- Раздел "Аккаунт" (нажать на своё имя в меню): смена логина и пароля, перенастройка 2FA на
  новый телефон, новые резервные коды, активные сессии с закрытием по одной, попытки входа.
  Блок безопасности входа переехал сюда из "Настроек".
- Восстановления пароля нет: сброс из консоли сервера панели - `vps-panel admin password`,
  `vps-panel admin 2fa` (и `vps-panel admin` - логин, 2FA, сессии).
- Панель без домена: если при установке не указать домен, она работает на `https://<IP>` с
  сертификатом Let's Encrypt на IP-адрес (Caddy продлевает сам). Домен добавляется позже -
  `vps-panel domain <имя>`; прежний адрес продолжает работать, агенты новой версии сами
  переходят на новый.
- "Настройки" - "Версия панели": ссылка на панель на GitHub.
- README: раздел возможностей и скриншоты.
- Окно подробностей доступности из России: подсказка о "худшей из двух проверок" - только у
  MTProxyL.

## 1.0.0-beta.7 - 12.10.2026

- Доступность из России: графики всех целей на одной шкале - 12 часов по получасам, у
  MTProxyL больше не "короче" и не "отстаёт". Проверки адреса и inbound-ов - в :00 и :30,
  каждая проверка MTProxyL (раз в 15 минут) попадает в историю, а не только каждая вторая.
- Нажатие на график доступности - окно с крупным графиком: выбираешь получас и видишь, из
  каких городов и сетей (AS) сервис виден, а из каких нет и с какой ошибкой. Зонды хранятся
  13 часов; для адреса и inbound-ов нужна новая версия агента (приедет за панелью).
- Команды: последний запуск в карточке сервиса виден целиком, кнопки - строкой ниже.

## 1.0.0-beta.1 - 12.10.2026

Первый релиз: панель ставится одной командой из готовых образов и обновляется из себя.

- Проверка кода на GitHub (Actions) на каждый push и pull request.
- Версия панели в /api/health и в интерфейсе.
- Установка одной командой (install.sh) из готовых образов ghcr.io, команда vps-panel на
  сервере: обновление с откатом при неудаче, канал stable или beta, статус, логи, снятие.
- Настройки, "Версия панели": новые релизы в своём канале со списком изменений, кнопка
  "Обновить", автообновление в заданный час, уведомление в Telegram о новой версии.
- Агенты обновляются сами после обновления панели (выключатель в "Версии панели").
- Расширение Firefox подписывает сама панель ключом API addons.mozilla.org из Настроек: у
  каждой установки свой ID и адрес обновлений.
- Уведомления в Telegram по событиям (19 событий в группах), окно настройки, отключение
  серверов, задержка "сервер пропал", события "сервис упал/работает" и "сбой бэкапа".
- Прокси для браузера (naive) ставится и на сервер самой панели: сертификат выпускает Caddy
  панели.
- Удаление прокси для браузера, 3X-UI, MTProxyL и OpenFlux сразу убирает привязки клиентов.
- Исправлено: "MTProxyL: адрес в ссылках" брал IP вместо имени из "Адреса для клиентов".
