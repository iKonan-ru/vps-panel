# Изменения

Версии - [semver](https://semver.org/lang/ru/): X.Y.Z - стабильный релиз, X.Y.Z-beta.N -
пре-релиз (канал "бета"). Текст раздела версии становится описанием релиза на GitHub.

## 1.0.0-beta.5 - не выпущена

- OpenFlux, поставленный без копии установщика (мастер приложения, старая версия): обновление
  ядра и автообновление больше не падают с "нет node-install.sh" - агент кладёт установщик
  закреплённой версии сам (нужна новая версия агента, она приедет за панелью).
- Обновление панели из Настроек: полоса хода появляется сразу после нажатия.

## 1.0.0-beta.4 - 12.10.2026

- Обзор сервера: блок "Хостинг" - перед "Доступами".

## 1.0.0-beta.3 - 12.10.2026

- Действия по всей панели блокируются, пока блок обновляет состояние: проверка версий
  MTProxyL больше не даёт начать обновление, сервер занят сразу после запуска действия,
  двойной тап не запускает дважды.
- Ключи root - отдельная вкладка "Ключи" в карточке сервера.
- Настройки: порядок "версия панели - бэкап - уведомления"; маршрут до Telegram - окно внутри
  уведомлений; смена канала сразу проверяет версии; во время обновления панели блок
  заблокирован.
- Ошибки Globalping - понятным текстом вместо куска ответа сервиса.
- Команды без счётчика вопросов.
- `vps-panel uninstall --full`: снять с сервера всё, что ставила панель, включая агента и
  VPN-сервисы; без ключа - только панель.
- README заново: установка в начале, дисклеймер, подробности - в docs/.

## 1.0.0-beta.2 - 12.10.2026

- Проверка обновления из панели на установке, переехавшей с исходников.
- tools/ship.sh больше не выкладывает исходники на сервер без явного "deploy": бой
  обновляется релизами.

## 1.0.0-beta.1 - 12.10.2026

Первый релиз: панель ставится одной командой из готовых образов и обновляется из себя.

- Проверка кода на GitHub (Actions) на каждый push и pull request.
- Версия панели в /api/health и в интерфейсе.
- Установка одной командой (install.sh) из готовых образов ghcr.io, команда vps-panel на
  сервере: обновление с откатом при неудаче, канал stable или beta, статус, логи, снятие.
- Настройки, "Версия панели": новые релизы в своём канале со списком изменений, кнопка
  "Обновить", автообновление в заданный час, уведомление в Telegram о новой версии.
- Агенты обновляются сами после обновления панели (выключатель в "Версии панели").
- Расширение Firefox подписывает сама панель ключом API addons.mozilla.org из Настроек: у
  каждой установки свой ID и адрес обновлений.
- Уведомления в Telegram по событиям (19 событий в группах), окно настройки, отключение
  серверов, задержка "сервер пропал", события "сервис упал/работает" и "сбой бэкапа".
- Прокси для браузера (naive) ставится и на сервер самой панели: сертификат выпускает Caddy
  панели.
- Удаление прокси для браузера, 3X-UI, MTProxyL и OpenFlux сразу убирает привязки клиентов.
- Исправлено: "MTProxyL: адрес в ссылках" брал IP вместо имени из "Адреса для клиентов".
